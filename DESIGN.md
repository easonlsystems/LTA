# LTA Design System

<!-- impeccable:design-schema 1 -->

## World

LTA feels like a live source relay inside its established black visual identity. A public URL moves from unavailable metadata into usable context through clear state changes, with luminous violet marking the moment the source arrives.

## Color and Material

- Preserve the established black canvas, soft neutral text, and luminous violet LTA accent.
- Layered dark surfaces carry interactive states without turning into generic boxed cards.
- Violet marks LTA, successful source transport, and primary actions.
- Warm orange is reserved for active retrieval or attention.
- Red appears only for a failed source state.
- Depth comes from subtle light, restrained glow, and surface tone.

## Typography and Composition

- Large editorial sans serif headlines explain the human benefit.
- Monospace labels carry URLs, source state, timing, and system evidence.
- The first viewport is a working comparison, with the headline and action attached to it.
- Avoid a long sequence of generic cards. Use open planes, connected state rails, and a compact route switchboard.

## Interaction

- Visitors choose a source and run the same prompt through both states.
- State changes progress from ready → reading → source ready, with visible cause and outcome.
- Primary activation stays adjacent to the successful result.
- Motion communicates transport and state. Focus, reduced motion, and reading states remain still.

## Information Architecture

- Homepage: immediate interactive proof and direct activation.
- Connect: guided Claude setup and troubleshooting.
- Sources: supported routes and limitations.
- Use cases: outcome-oriented scenarios.
- Pricing: units and plans.
- Developers: MCP and REST integration.

## Responsive Behavior

- Desktop shows both outcomes side by side.
- Mobile sequences the two states vertically and keeps source selection horizontally scrollable.
- The product claim and run control remain above the fold on common phone sizes.

## Accessibility

- All state controls use native buttons and expose selected/expanded state.
- Dynamic results use a polite live region.
- Focus rings are high contrast.
- Reduced-motion users receive immediate state changes without animation.
