# Homepage Surface Brief

## Mode

Persuade

## Objective

Make a first-time visitor understand LTA by operating a credible source comparison immediately, then move them into the direct Claude connector flow.

## Structure

1. Live source relay in the first viewport using the established black and violet palette: claim, source selector, real prompt, run control, paired outcomes.
2. Compact activation rail explaining the three setup moments.
3. Route switchboard for Sources, Use cases, Pricing, and Developers.
4. Final direct Claude activation.

## Success

The visitor can explain the product after one interaction and can start the prefilled Claude setup without searching a directory or creating an API key.

## Constraints

Use only truthful source capabilities and the recorded Instagram case. Preserve keyboard access, reduced motion, mobile comprehension, and honest video/image limitations.
